Project Overview

{{ app_name }} is a Final Year Computer Science project developed to help JUPEB (Joint Universities Preliminary Examinations Board) students predict their academic performance using advanced Machine Learning techniques.

The system utilizes a Random Forest Classification algorithm trained on synthetic student data to analyze various academic and behavioral factors, providing accurate performance predictions and personalized recommendations.

Dataset Information

The system is trained on a synthetic dataset of 1,500 JUPEB student records containing the following features:

Numerical Features
  • CA Score (0-40)
  • Attendance Rate (0-100%)
  • Mock Exam Score (0-100)
  • Study Hours per Week
  • Stress Level (1-10)
Categorical Features
  • Subject Combination
  • Gender
  • Study Resources
  • Behavioural Pattern
